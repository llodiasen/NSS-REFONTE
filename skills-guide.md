# 📦 Guide Complet des Skills — Web, E-commerce, Design, SEO

> **Principe :** N'installe jamais tous les skills en même temps.
> Active uniquement ceux du projet en cours pour économiser les tokens.

---

## ⚡ Commande d'installation

```bash
# Syntaxe générale
npx skills add https://github.com/<owner>/<repo> --skill <nom-du-skill>

# Exemple
npx skills add https://github.com/anthropics/skills --skill frontend-design
```

## 💡 Rappels importants

> ⚠️ **Ne jamais tout installer en même temps** — sature le context window de l'agent.

> ✅ **Installer par phase** — l'agent reste focus et les réponses sont meilleures.

> 🔁 **À chaque nouveau projet** — désinstaller les anciens skills, installer les nouveaux.

> 💰 **L'installation = gratuit** — les tokens sont consommés uniquement quand l'agent utilise les skills.
