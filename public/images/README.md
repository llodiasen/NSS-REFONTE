# Images — wasafrica.org (NSS)

## Structure

| Dossier | Contenu | Source |
|---------|---------|--------|
| logo/ | Logo NSS couleur + version blanc | WordPress /wp-content/ |
| hero/ | 1-2 photos hero (femmes rurales terrain) | WordPress média |
| leaders/ | 9 portraits des leaders des associations fondatrices | WordPress /nos-associations/ |
| partenaires/ | 5 logos partenaires (Grassroots, Agroecology Fund, Fonds Égalité, Thousand Currents, Fahamu) | WordPress /nos-partenaires/ |
| programmes/ | Photos CIFAP Niaguis + EMMAP | WordPress /event/ |
| galerie/ | Toutes les photos de la galerie NSS | WordPress /galerie-nss/ |
| actualites/ | Images couverture des articles légitimes (Foire Djimini, CIFAP 2024, Thousand Currents) | WordPress /actualites/ |
| og/ | og-image.jpg (1200x630) pour Open Graph SEO | À créer |

## Formats acceptés
- Photos : .jpg ou .webp (next/image convertit automatiquement)
- Logos : .svg (préféré) ou .png avec transparence
- Taille max recommandée : 400 Ko par image avant optimisation

## Nommage
- Tout en minuscules, tirets : `cifap-niaguis-2024.jpg`
- Leaders : `prenom-nom.jpg` (ex: `esther-boake.jpg`)
- Logos partenaires : `nom-partenaire.svg` (ex: `grassroots-international.svg`)
